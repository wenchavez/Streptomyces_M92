# Streptomyces M-92: Analysis of Biosynthetic Gene Clusters

## Overview

This repository contains the computational workflow developed to support the identification, structural prediction, and molecular characterization of putative natural products associated with the biosynthetic gene clusters (BGCs) of *Streptomyces morropensis* sp. nov. M-92.

The workflow integrates results previously generated using the antiSMASH web platform and downloaded for downstream analysis, PRISM4 structural predictions, reference-based homology analysis against the MIBiG database, and cheminformatic characterization using RDKit.

The computational analysis focuses on 19 prioritized BGC regions identified during the genomic analysis of the strain.

## Workflow

The workflow consists of three main stages.

### 1. BGC region validation and structural prediction

**Script:** `01_validate_regions.py`

This script processes the GenBank files (`.gbk`) previously downloaded from the antiSMASH web platform.

Main tasks:

- Processes the 19 prioritized antiSMASH BGC regions.
- Organizes the available PRISM4 structural predictions and associated scaffold information.
- Retrieves predicted SMILES and scaffold information.
- Records the processing status of each prioritized region.
- Generates a consolidated table of processed regions.

### 2. Structural homology analysis against MIBiG

**Script:** `02_mibig_homology.py`

This script performs reference-based structural assignment using the MIBiG database.

Main tasks:

- Compares BGC-associated protein sequences against the MIBiG reference database.
- Uses DIAMOND to identify homologous biosynthetic gene clusters.
- Evaluates region-to-region similarity and core-gene support.
- Assigns putative structural candidates based on the established selection criteria.
- Retrieves available compound information and SMILES from MIBiG.

### 3. Molecular descriptor calculation

**Script:** `03_calculate_descriptors.py`

This script integrates PRISM4-derived and MIBiG-derived structures for molecular characterization using RDKit.

Main tasks:

- Validates and canonicalizes SMILES representations.
- Calculates molecular descriptors, including:
  - Molecular weight
  - LogP
  - Topological polar surface area (TPSA)
  - Hydrogen-bond donors (HBD)
  - Hydrogen-bond acceptors (HBA)
  - Rotatable bonds
  - Ring presence
- Generates Morgan fingerprints (radius = 2; 2048 bits).

## Structural prediction dataset

The combined dataset comprises **89 putative structures**:

- **76 structures** derived from PRISM4 predictions.
- **13 structures** obtained through MIBiG-based homology analysis.

All structures were subjected to molecular characterization using RDKit, generating molecular descriptors and Morgan fingerprints.

### Directory description

- `Scripts/`: Python scripts implementing the computational workflow.
- `Regiones antiSMASH/`: Previously downloaded GenBank files containing antiSMASH results.
- `Datos MIBiG/`: Reference files and databases required for MIBiG-based homology analysis.
- `sequences/`: Protein sequences used in the computational analysis.
- `results/`: Output files generated by the workflow.

## Requirements

The workflow uses Python 3.14.7 and the following Python packages:

- pandas 3.0.5
- RDKit 2026.03.5

The Python dependencies are listed in `requirements.txt`.

DIAMOND is required as an external tool for protein sequence similarity searches and must be installed separately.

## Reference databases and external resources

### antiSMASH

The antiSMASH results used in this study were generated through the antiSMASH web platform and downloaded before running the computational workflow.

The corresponding GenBank files (`.gbk`) must be placed in the `Regiones antiSMASH/` directory.

### MIBiG

The MIBiG reference database is required for the BGC homology analysis performed in the second stage.

The analysis uses MIBiG version 4.0. Users must obtain the corresponding reference files separately, including:

- MIBiG JSON files.
- MIBiG GenBank files.
- MIBiG protein sequence database in DIAMOND format (`.dmnd`).

The downloaded files must be placed in the `Datos MIBiG/` directory, following the directory structure expected by the scripts.

For reproducibility, the same MIBiG release used in this study should be employed.

## Execution

Run the scripts sequentially from the repository root directory:

```bash
python Scripts/01_validate_regions.py
python Scripts/02_mibig_homology.py
python Scripts/03_calculate_descriptors.py
```

Before execution, ensure that:

- The antiSMASH GenBank files are available in the corresponding input directory.
- The MIBiG 4.0 reference files and databases have been downloaded and configured.
- DIAMOND is installed and accessible from the command line.
- The Python dependencies listed in `requirements.txt` are installed.
- Input and output paths match the repository structure.

Install the Python dependencies using:

```bash
pip install -r requirements.txt
```

## Outputs

The main output files generated by the workflow include:

- `processed_regions.csv`: consolidated information on the 19 prioritized BGC regions, including processing status, predicted SMILES, and scaffold information.
- `putative structures.csv`: MIBiG-based structural assignments and associated putative chemical structures.
- `molecular_descriptors.csv`: molecular characterization dataset containing canonical SMILES, molecular descriptors, and Morgan fingerprints.

All generated output files are stored in the `results/` directory.
